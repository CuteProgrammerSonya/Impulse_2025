##Общие вопросы по C++##
1. **Примеры использования static.** static может использоваться для функций и полей в классе. При этом статическое поле не является членом класса, а может служить, например для подсчёта количества экземпляров класса. Для работы со статическими полями используются статические функции. Можно использовать static для задания констант класса. Также static позволяет реализовать паттерн синглтон.
2. **Примеры использования using.** using может использоваться для подключения пространства имён (using namespace std;), а также для определения собственных псевдонимов, например для типов данных (using ullong = unsigned long long;).
3. **Примеры использования inline.** inline используется для встроенных функций, чтобы компилятор подставил тело функции в место её вызова на этапе компиляции, чтобы не вызывать функцию во время выполнения программы.

<u>Задача 2.</u>
Решение в папке: Task_2. В Task_2->main.cpp основная функция программы - ввод числа и получения его факториала.

Для решения задачи был написан класс BigInt, работающий с длинной арифметикой, так как значение факториала 255 не убирается ни в один стандартный тип данных.

В классе каждое число хрпнится в векторе по разрядам, причём сначала идут последние цифры числа, а затем первые. Это создано для удобного умножения на целое число. Оно организовано по правилу умножения столбиком. Класс использует перегрузки операторов = и *= для более удобной работы. Также полученное число представляется в виде строки цифр.

Для более быстрого вычисления факториала было принято решение вычислить факториалы всех чисел заранее и сохранить результаты в таблице факториалов. Для получения факториала нужного числа достаточно просто обратиться к таблице.

Класс FactorialsTable реализован для работы с такой таблицей. В нём осуществляется подсчёт всех факториалов путём обращения к предыдущей ячейки и домножения на текущее число, факториал которого нужно получить. Таблица является статическим полем, для того чтобы можно было создать её единственный экземпляр. Методы являются статическими, потому что работают со статическим полем.

<u>Задача 3.</u>

Решение в папке: Task_3->main.cpp

Рекурсивный алгоритм меняет первый элемент строки со следующим элементом и для каждой такой замены применяется снова. Для того, чтобы не учитывать одинаковые строки, которые могут получиться, если буквы в исходной строке повторяются, используется множество unordered_set.

Итеративный алгоритм работает по такому же принципу, только использует стек пар, элементами которых являются строка и индекс замены элементов. Индекс нужен для регулирования остановки выполнения цикла. Когда он достигает конца строки, то менять элементы уже не нужно, все варианты замен были испробованы.
